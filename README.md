# Now Mirror

A macOS widget (WidgetKit: small, medium, large) that mirrors the system **Now Playing**: artwork, title, artist, with previous / play-pause / next buttons. It works with whatever app publishes to Now Playing (Music, Spotify, browsers, and so on).

> **Independent project, not affiliated with Qobuz, Spotify or Apple.** These names are mentioned for information only. No token or API of these services is used.
>
> **Outside the App Store, by design**: Now Mirror reads the system state through MediaRemote, a private API, so it cannot be published on the Mac App Store.

## Install

1. Download `NowMirror-x.y.dmg` from the [Releases](../../releases) and drag the app to `/Applications`.
2. The app is neither signed with a developer certificate nor notarized. On first launch, **right-click › Open**, or from a terminal:
   ```bash
   xattr -dr com.apple.quarantine /Applications/NowMirror.app
   ```
3. On first launch the settings window opens. Turn on **Open at login** so the widget keeps updating (the menu bar icon can be hidden there too).
4. Add the widget: right-click the desktop › *Edit Widgets* › "Now Mirror". If it does not show up, open the app first, then run `killall chronod`.

The app must stay running: it reads Now Playing and hands it to the widget. If the icon is hidden, open Now Mirror again to bring the settings back.

## How it works

```
/usr/bin/perl + mediaremote-adapter  ──stream (JSON)──▶  Now Mirror (menu bar app, not sandboxed)
                                                              │ merges the updates
                                                              ▼
                        ~/Library/Application Support/NowMirror/{state.json, artwork-*.jpg}
                                                              │ read-only
                                                              ▼
                                              WidgetKit extension (sandboxed)
```

- The **relay** (`App/Relay.swift`, part of the menu bar app) runs `mediaremote-adapter stream`, merges the partial updates, writes the state and the artwork (scaled to 400 px, since widgets reject large images), then reloads the widget.
- The widget reads that folder through the `com.apple.security.temporary-exception.files.home-relative-path.read-only` entitlement (no app group without a developer certificate).
- The buttons (AppIntents) post a distributed notification `dev.nowmirror.command.*`; the relay translates it into `mediaremote-adapter send` for the active app.
- At startup the relay runs the adapter's `test` command. On failure, the settings window and the menu show an error. The test briefly creates a fake media entry.

## Build

Requirements: Xcode, `xcodegen` (`brew install xcodegen`), `git`.

```bash
./build.sh      # adapter (clang, universal) + project + xcodebuild, ad-hoc signature → build/NowMirror.app
./package.sh    # → dist/NowMirror-x.y.dmg and .zip + SHA256SUMS
./test.sh       # unit tests (state merging, artwork scaling, shared model)
```

Pushing a `vX.Y.Z` tag publishes a GitHub release automatically (`.github/workflows/release.yml`). The icon is generated by `swift tools/make-icon.swift`.

## Limits and risks

- **Private API**: MediaRemote is undocumented. Since macOS 15.4 access goes through `/usr/bin/perl`, a system binary that keeps the right to load it; a macOS update can break this workaround without notice. The adapter version is pinned in `build.sh`.
- **Ad-hoc signature**, no notarization: Gatekeeper asks for confirmation, and the file-read exception is not guaranteed across macOS versions.
- **One controlled app**: `send` targets the app active in Now Playing, not an app you pick.
- The widget refreshes when the track or state changes, with a slight delay. No real-time progress.
- The artwork can arrive after the title.
- Only tested on macOS 27 (Apple Silicon).
- The tests cover the pure logic (state merging, artwork scaling, shared model); the widget, the sandbox and the adapter are checked by hand.
